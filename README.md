# Projeto-Final---Front-end

Projeto final da disciplina de front-end.
O Política Acessível é um site com fim de facilitar e democratizar o entendimento abrangente de assuntos sobre política. Com fim de informar os cidadãos a saberem o que está acontecendo no cenário público social que envolve a todos os cidadãos. Para o desenvolvimento do projeto foi usado somente: HTML e CSS. Em outras atualizações iriam ser desenvolvidas e atribuídas com o passar do tempo, separação por estado, projetos por candidatos e outras funções que iriam vir em outras versões.
