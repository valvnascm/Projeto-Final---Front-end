O que é a Política Acessível?

É um projeto acadêmico que reúne informações políticas em linguagem simples. O site tem ajuste de tamanho de letra, modo de alto contraste e navegação por teclado. Todo o conteúdo é apenas didático, e os dados são fictícios.
